- Jose Carrion

## Descripción
Proyecto refactorizado aplicando principios de *Código Limpio, **SOLID* y *MVC* para la Tarea #1 de Unidad 4.

## Estructura del Proyecto

src/
├── uni1a/              # Modelos (Pelicula, Serie, etc.)
├── repository/         # Manejo de archivos CSV
├── controller/         # Controlador
├── view/               # Vista de consola
└── poo/
    └── PruebaAudioVisual.java

test/                   # Pruebas unitarias JUnit 5

## Cómo ejecutar en VS Code

1. Abre la carpeta en VS Code
2. Asegúrate de tener instalada la *Extension Pack for Java*
3. Presiona F5 o ejecuta PruebaAudioVisual.java
4. Para pruebas: Click derecho en archivos de test → "Run Test"
